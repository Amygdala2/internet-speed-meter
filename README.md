# Internet Speed Meter

Тестовое задание: Python-скрипт измеряет скорость скачивания с указанного HTTP(S)-адреса. Выполняет **10 запросов последовательно**, полностью читает каждый ответ и выводит среднее время запроса, суммарный объём данных и скорость.

## Запуск

Нужен **Python 3.10 или новее**. Внешних зависимостей нет.

```bash
git clone https://github.com/Amygdala2/internet-speed-meter.git
cd internet-speed-meter
python speed_meter.py "https://your-server.example/large-image.jpg"
```

Замените пример URL на прямую ссылку на доступную большую картинку или другой файл. Ссылка выше иллюстрирует формат и не предназначена для реального замера. В Windows вместо `python` можно использовать `py`; в Linux/macOS обычно `python3`.

При необходимости задайте таймаут:

```bash
python speed_meter.py "https://your-server.example/large-image.jpg" --timeout 60
python speed_meter.py --help
```

`--timeout` по умолчанию равен 30 секундам. Это таймаут блокирующей сетевой операции, а не общий лимит времени скачивания: большой файл может скачиваться дольше, если данные продолжают поступать.

## Вывод

Иллюстрация формата (конкретные значения зависят от сети и файла):

```text
Request 1/10: 0.500000 s, 2000000 bytes
...
Request 10/10: 0.500000 s, 2000000 bytes
Average request time: 0.500000 s
Downloaded: 20000000 bytes (20.000000 MB)
Download speed: 4.000000 MB/s
Download speed: 32.000000 Mbit/s
```

## Как считается результат

- Время: `time.perf_counter()` от начала запроса до полного чтения тела ответа; сюда входят установление соединения и ожидание сервера.
- Объём: фактическое количество прочитанных байтов тела ответа, без HTTP-заголовков и служебного сетевого трафика.
- Среднее время: сумма длительностей / 10.
- Скорость: сумма байтов / сумма длительностей / 1 000 000, в **МБ/с** (MB/s).
- **Мбит/с** (Mbit/s) = МБ/с × 8. Используются десятичные единицы: 1 МБ = 1 000 000 байтов.

Скорость рассчитывается по общему объёму и времени; это корректно и при разных размерах ответов. Скрипт читает файл порциями по 64 КиБ, не хранит его целиком в памяти и не сохраняет на диск. Запрашивает несжатый ответ и отключение кеширования; сервер может не соблюдать эти заголовки. Перенаправления обрабатывает стандартная библиотека, поэтому один замер при редиректе может включать несколько HTTP-переходов.

При ошибке HTTP, недоступности сети, таймауте, пустом или оборванном ответе программа останавливается с кодом 1 и сообщает номер запроса. Итоговая скорость в этом случае не выводится. Неверные аргументы дают код 2, прерывание Ctrl+C во время скачивания — 130. Нет скрытых повторных попыток.

Замер показывает скорость скачивания **до выбранного сервера**, включая задержки его ответа, а не гарантированную пропускную способность интернет-тарифа. Для практического замера используйте достаточно большой файл и учитывайте, что он будет скачан 10 раз.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты запускают реальный локальный HTTP-сервер и скрипт как отдельный процесс: проверяют 10 последовательных скачиваний, фактические байты, вывод расчётов и обработку ошибок. Отдельно проверяется формула на заранее известных числах. Проверки не требуют интернета и не доказывают скорость внешнего подключения.
